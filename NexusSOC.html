Security Operations Center OS

Suite de ferramentas para analistas de segurança da informação. Todas as funções criptográficas usam Web Crypto API (nativa do browser). Nenhum dado sai do dispositivo.

Uso exclusivamente educacional. Não execute ataques a sistemas sem autorização.
