# AGI Core — Adaptive Hebbian Attention Network (AHA-Net)

Arquitetura modular inspirada em cognição biológica:
- **Percepção** → vetoriza entradas multimodais
- **Memória** → grafo associativo dinâmico (skip-gram + hebbian)
- **Raciocínio** → motor simbólico-neural híbrido
- **Aprendizado** → AHA-Net (Hebbian + backprop esparso)
- **Interface** → HTML/JS em tempo real via WebSocket
