What This Actually Is

Architecture: 1 transformer block · 2 attention heads · 32-dim embedding · 32-char context · character tokenizer.

Real components: reverse-mode autograd (V class), multi-head self-attention with causal mask, feed-forward MLP, RMS-like normalization, Adam optimizer, cross-entropy loss.

Honest scope: ~20K parameters trained on ~5KB of curated dialogue. This is a real transformer that really trains and really generates — but it is not GPT-4. Expect short, imperfect, pattern-echoing answers. The point is that gradients flow, attention weights update, and loss drops — all in ~400 lines of vanilla JS with zero dependencies and zero network calls.

Privacy: Nothing leaves your device. The model state persists in localStorage. Reload the page and it's still there.
