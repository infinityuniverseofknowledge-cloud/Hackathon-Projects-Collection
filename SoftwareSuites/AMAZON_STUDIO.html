Armazenamento

LAUNCH STUDIO

Plataforma local-first para criadores publicarem produtos digitais com assistência IA, validação de qualidade e analytics transparente.

100% Local

Todos os dados vivem no seu navegador. Nada é enviado para servidores.

Open Source

Arquivo HTML único, sem dependências externas, sem build.

IA Transparente

Assistente local rule-based por padrão. API externa é opcional.

Privacidade

Esta aplicação armazena produtos, pedidos, favoritos e configurações apenas no localStorage do seu navegador. Nenhum dado é transmitido automaticamente. Para uso multi-usuário ou sincronização entre dispositivos, é necessário um backend com autenticação.
