AETHER is a local-first AI orchestration ecosystem: workflow DAG engine, Monte Carlo simulation, gradient descent optimization, Dijkstra pathfinding, keyword knowledge index, project factory — all deterministic, all inspectable, all running in your browser.

What's actually running
  • Workflow engine — DAG with topological sort, cancellable, retries
  • Simulation — seeded Monte Carlo, numerical integration (trapezoidal, Simpson)
  • Optimization — gradient descent with convergence trace + SVG plot
  • Graph — BFS, DFS, Dijkstra on a live 8-node weighted graph
  • Knowledge — TF keyword scoring over indexed docs
  • Factory — manifest generator with integrity hash + download
  • Console — every action emits a timestamped event
  • Persistence — localStorage with corruption recovery
Honest scope

✓ IMPLEMENTED — all algorithms above, all UI, all persistence
